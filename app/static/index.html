Real-Time Fraud Detection

Pipeline de detecção de fraude em tempo real: transações entram por um tópico Kafka, um serviço calcula features por usuário, um modelo XGBoost dá o score de risco e tudo é gravado no PostgreSQL — este painel lê o resultado ao vivo.

KafkaXGBoostFastAPI PostgreSQLSSEPSI (drift)

Dados 100% sintéticos. O feed vem de um simulador com o relógio acelerado: os horários dos eventos são simulados; latência, janelas e alertas usam o relógio real. Não use este modelo com dados financeiros reais.
